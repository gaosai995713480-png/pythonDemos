# 侧边导航栏设计文档

## 需求

将首页居中的导航卡片网格改为左侧可收放的侧边栏：
- 展开时：显示图标 + 文字标签
- 收起时：只显示图标（竖排）
- 点击按钮切换展开/收起
- 收放状态持久化到 localStorage

## 变更文件

| 操作 | 文件 | 说明 |
|------|------|------|
| 新增 | `frontend/src/components/NavSidebar.vue` | 侧边导航栏组件 |
| 修改 | `frontend/src/views/HomeView.vue` | 替换 nav-grid 为 NavSidebar |

## 组件设计

### NavSidebar.vue

- **Props**: 无
- **State**: `expanded`（boolean，从 localStorage 读取，默认 true）
- **定位**: `position: fixed; left: 0; top: 50%; transform: translateY(-50%)`
- **展开宽度**: ~160px，收起宽度: ~56px
- **过渡动画**: `transition: width 0.3s ease`
- **切换按钮**: 底部 ◀/▶ 按钮
