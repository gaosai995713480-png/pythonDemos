# 点歌台（Jukebox）功能设计

访客可以在点歌台搜索并推荐歌曲给情侣，附上祝福语和可选昵称。情侣（已登录）可以一键采纳推荐歌曲到自己的歌单。其他访客可以为推荐点赞。

## 需求汇总

| 决策项 | 结论 |
|--------|------|
| 登录要求 | 无需登录即可点歌 |
| 身份标识 | 可选昵称，默认"匿名访客" |
| 采纳机制 | 情侣（已登录）一键采纳到歌单 |
| 页面形式 | 独立页面 `/jukebox`，首页导航入口 |
| 防刷策略 | IP 限频（同一 IP 每小时最多 5 首） |

## 架构设计

### 数据模型

新增数据表 `love_song_requests`：

```sql
CREATE TABLE IF NOT EXISTS `love_song_requests` (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    song_id VARCHAR(20) NOT NULL,        -- 平台歌曲 ID
    song_name VARCHAR(100) NOT NULL,     -- 歌曲名
    artist VARCHAR(100) NOT NULL,        -- 歌手
    platform VARCHAR(20) NOT NULL DEFAULT 'netease',
    nickname VARCHAR(30) DEFAULT '匿名访客',
    message VARCHAR(100) DEFAULT '',     -- 祝福语
    likes INT NOT NULL DEFAULT 0,
    ip VARCHAR(45) NOT NULL,             -- 推荐者 IP（防刷用）
    is_adopted TINYINT NOT NULL DEFAULT 0,  -- 是否已被采纳
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

点赞去重表 `love_song_requests_likes`：

```sql
CREATE TABLE IF NOT EXISTS `love_song_requests_likes` (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    request_id BIGINT NOT NULL,
    ip VARCHAR(45) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE KEY uniq_request_ip (request_id, ip)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 后端 API

新增路由文件 `backend/routers/jukebox.py`，挂载前缀 `/api`：

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/api/jukebox` | 获取推荐列表（按点赞数降序） | 无 |
| POST | `/api/jukebox` | 提交歌曲推荐 | 无（IP 限频） |
| POST | `/api/jukebox/like` | 为推荐点赞 | 无（IP 去重） |
| POST | `/api/jukebox/adopt` | 采纳推荐到歌单 | 需登录 |

#### API 详细定义

**GET /api/jukebox**
- 参数：`limit`（默认 50）
- 返回：`[{id, song_id, song_name, artist, platform, nickname, message, likes, is_adopted, created_at}]`
- 排序：按 likes 降序，created_at 降序

**POST /api/jukebox**
- Body：`{song_id, song_name, artist, platform, nickname?, message?}`
- 防刷：同一 IP 每小时最多 5 次推荐
- 返回：`{ok: true, id: <new_id>}`

**POST /api/jukebox/like**
- Body：`{id: <request_id>}`
- 逻辑：IP 去重，复用弹幕点赞的模式
- 返回：`{ok: true, id, likes, liked: boolean}`

**POST /api/jukebox/adopt**
- Body：`{id: <request_id>}`
- 认证：需要登录（`require_auth`）
- 逻辑：将推荐歌曲插入 `love_music` 表，并标记 `is_adopted = 1`
- 返回：`{ok: true}`

```
        └── 采纳按钮（仅登录用户可见）
```

### 交互流程

1. 访客打开点歌台，看到现有推荐榜
2. 访客搜索歌曲 → 选择一首 → 弹出推荐表单（昵称+祝福语）→ 提交
3. 推荐出现在列表中
4. 其他访客可以点赞
5. 情侣（已登录）看到推荐后点击"采纳"→ 歌曲自动加入歌单，该推荐标记为"已采纳"

### 防刷策略

- 同一 IP 每小时最多推荐 5 首歌
- 点赞 IP 去重（复用弹幕点赞模式）
- 昵称和祝福语长度限制（昵称 ≤ 30 字符，祝福语 ≤ 100 字符）

### 视觉风格

- 复用现有 glassmorphism 风格（`var(--glass-bg)`, `backdrop-filter: blur()`）
- 推荐卡片使用渐变边框
- 已采纳的歌曲增加 ✅ 标记和高亮效果
- 响应式布局，复用 `.nav-card` 样式模式
