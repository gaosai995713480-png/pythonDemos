# 做菜食谱功能实施计划

> 本计划用于按任务逐步实现“我们的小厨房”。实现必须遵循 TDD：先写失败测试，再写最小实现，再验证通过。

## 目标

将 GitHub HowToCook 食谱作为上游快照集成到本项目，通过同步脚本解析并写入 MySQL；运行时只访问本项目数据库和 API；前端提供“我们的小厨房”原生页面，支持菜谱库、收藏、想做、已做、做饭记录、纪念日菜单和随机推荐。

## 验收标准

1. 同步脚本 dry-run 能扫描 HowToCook 快照并输出统计。
2. 解析器能提取标题、分类、材料、步骤、小贴士、hash 和原文。
3. 导入器按 `source + source_path` upsert，hash 未变跳过，hash 变化更新。
4. API 列表、分类、详情、随机推荐可用。
5. API 支持收藏、想做、做饭记录、菜单计划。
6. `/cookbook` 页面可浏览、搜索、筛选、查看详情、收藏、想做、记录已做、维护菜单。
7. 运行时不请求 GitHub，不实时读取 Markdown。
8. 所有验证命令通过。
